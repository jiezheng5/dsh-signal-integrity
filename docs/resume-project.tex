\textbf{Signal-Integrity Analysis Plugin for an LLM Agent Harness} \hfill 2026 \\
\emph{Unofficial community plugin for DeepSeek Harness; TypeScript, Python (scikit-rf, NumPy, Matplotlib)} \\
\href{https://github.com/jiezheng5/dsh-signal-integrity}{github.com/jiezheng5/dsh-signal-integrity}
\begin{itemize}
  \item Built an agent tool suite that turns Touchstone S-parameter files into
        engineer-reviewable reports: the agent inspects a file, asks the user for
        the device type and port topology it cannot infer, runs the matching
        analysis, and returns plots inline in chat plus an HTML/CSV/JSON report.
  \item Designed the tool contract so the model cannot skip physics it does not
        know: \texttt{si\_inspect} returns interpretation questions shaped for
        the harness's ask-user tool, and \texttt{si\_analyze} refuses incomplete
        interpretations or a file whose SHA-256 changed since inspection.
  \item Implemented lumped-element extraction (series $L$, $Q$, $R$; series
        $C$, ESR) for one-port, two-terminal differential
        ($Z_{11}{+}Z_{22}{-}Z_{12}{-}Z_{21}$) and through-fixture ($1/Y_{11}$)
        terminations, with self-resonance detection and per-point validity
        labels so no wrong-sign or beyond-resonance value is reported as a
        component parameter.
  \item Adopted IEEE P370 frequency-domain quality metrics (passivity,
        reciprocity, causality) through scikit-rf alongside exact per-frequency
        checks that locate violations; verified on synthetic networks with known
        defects (active, non-reciprocal, anti-causal).
  \item Isolated numerical work in a JSON-over-stdio Python worker spawned per
        call with its own memory limit, mirror-tested protocol on both sides,
        and cooperative cancellation; CI runs typecheck, vitest, ruff, and pytest
        on every push.
\end{itemize}

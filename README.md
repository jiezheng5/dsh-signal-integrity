# DSH Signal Integrity

An unofficial community plugin for DeepSeek Harness that provides agent-guided Touchstone analysis and signal-integrity reporting.

## Status

Initial development. The first release will inspect Touchstone files, collect device and port-topology information, evaluate data quality, and generate device-specific reports.

## Planned analyses

- Passivity, reciprocity, and qualified causality diagnostics
- Inductance and quality factor
- Capacitance
- Transmission-line insertion loss, return loss, and characteristic impedance
- Multiport connector and interposer transmission reports

This project is independently developed and maintained and is not an official DeepSeek project.
